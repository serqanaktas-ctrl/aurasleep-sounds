# AuraSleep sounds

Downloadable sleep-sound packs for the **AuraSleep** app, served from GitHub Releases (direct asset URLs, no GitHub API).

- Manifest (always latest): `https://github.com/serqanaktas-ctrl/aurasleep-sounds/releases/latest/download/manifest.json`
- This pack: tag `sounds-2026.11.1`, schema 1, 43 downloadable sounds + 8 APK-bundled candidates (`bundled/`).
- Format: AAC-LC in `.m4a`, 44.1 kHz stereo, 96 kbps, seamless loops (crossfaded loop point), ≈ −18 LUFS integrated, peaks ≤ −1 dBFS after decoding.
- Licences: CC0 1.0 or original AuraSleep works only — see [LICENSES.md](LICENSES.md).

## Releasing a new pack

1. Edit `tools/catalog.py`, run `tools/gen.py`, `tools/process.py`, `tools/build.py` (needs the raw CC0 downloads, see LICENSES.md).
2. Bump the tag (`sounds-YYYY.MM.n`) in `tools/build.py`, create a new release with every `.m4a` and `manifest.json` as assets. The app follows `releases/latest`.
