# Licenses / Lisanslar

Every sound in this repository and its releases is either **CC0 1.0 (public-domain dedication)** or an **original AuraSleep work** generated by the code in `tools/` (owned by the AuraSleep project, Serkan Aktaş).
No CC BY, Pixabay-licence, "royalty free", Jamendo, soundjay, freepd or other non-CC0 material is used.

Verification: each third-party file's licence was read from its Wikimedia Commons file page (Commons API `extmetadata`: `LicenseShortName = CC0`, `License = cc0`) on 2026-11-14, re-checked automatically at manifest build time. Recordings were trimmed, high-passed (30 Hz), crossfade-looped, loudness-normalised (≈ −18 LUFS) and AAC-encoded; CC0 permits this without attribution, credits are given as a courtesy.

## Rejected sources / Reddedilen kaynaklar

- soundjay (both former fallback tracks): "royalty free" licence, not CC0 — removed.
- Jamendo, Pixabay, freepd (current alarm library): not CC0 (CC BY / Pixabay licence / own terms) — not used.
- Freesound originals: most require login to download; only files mirrored on Wikimedia Commons with a CC0 tag were used.
- Commons files tagged only "Public domain" (e.g. PD-self uploads by *stephan*, *ezwa*, *cori*): skipped, because the app's licence filter accepts only CC0 / owned strings and we did not want to relabel them.
- `Ambient Kitchen Sounds.wav` (CC0): licence fine, rejected for sleep suitability (dish clatter).
